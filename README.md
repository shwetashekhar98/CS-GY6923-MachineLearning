# **CS-GY6923 Machine Learning Assignments**

This repository contains the assignments completed for the **CS-GY6923 Machine Learning** course. Each assignment delves into essential machine learning concepts, algorithms, and practical applications.

## **Contents**
The repository is structured as follows:

- **`ML_Inet_FirstAssignment.ipynb`**  
  Introduction to machine learning basics: data preprocessing, exploratory data analysis, and simple regression implementation.

- **`ML_Inet_SecondAssignment.ipynb`**  
  Implementation of classification algorithms: logistic regression, decision trees, and performance evaluation using precision, recall, and F1-score.

- **`ML_Inet_Assignment3.ipynb`**  
  Application of unsupervised learning techniques: K-means clustering, PCA, and high-dimensional data visualization.

- **`ML_Assignment_4_1.ipynb`**  
  Exploration of ensemble methods: bagging, boosting, and random forests for enhanced classification accuracy.

- **`Assignment3.ipynb`**  
  Optimization techniques: gradient descent, cost function analysis, and hyperparameter tuning.

- **`MLAssignment7.ipynb`**  
  Neural network implementation: feedforward networks, activation functions, and backpropagation for deep learning tasks.

## **How to Use**
1. Clone this repository:
   ```bash
   git clone https://github.com/shwetashekhar98/CS-GY6923-MachineLearning.git
   ```
2. Open the assignment folder.
3. Use Jupyter Notebook or JupyterLab to open the `.ipynb` files:
   ```bash
   jupyter notebook filename.ipynb
   ```
