# CS-GY6923 Machine Learning INET FALL 2024 Assignments

This repository contains the assignments, lecture notes, and tutorials for the CS-GY6923 Machine Learning course. Each resource delves into essential machine learning concepts, algorithms, and practical applications.

## Contents

### Assignments
1. **ML_Inet_FirstAssignment.ipynb**
   - Introduction to machine learning basics: data preprocessing, exploratory data analysis, and simple regression implementation.

2. **ML_Inet_SecondAssignment.ipynb**
   - Implementation of classification algorithms: logistic regression, decision trees, and performance evaluation using precision, recall, and F1-score.

3. **ML_Inet_Assignment3.ipynb**
   - Application of unsupervised learning techniques: K-means clustering, PCA, and high-dimensional data visualization.

4. **ML_Assignment_4_1.ipynb**
   - Exploration of ensemble methods: bagging, boosting, and random forests for enhanced classification accuracy.

5. **Assignment3.ipynb**
   - Optimization techniques: gradient descent, cost function analysis, and hyperparameter tuning.

6. **MLAssignment7.ipynb**
   - Neural network implementation: feedforward networks, activation functions, and backpropagation for deep learning tasks.

### Tutorials
1. **M1_Python ML Basics.ipynb** - Overview of Python basics for machine learning.
2. **M3LogisticRegressionTutorial.ipynb** - Logistic regression techniques and applications.
3. **M4_SVM_MNIST.ipynb** - Support Vector Machines applied to the MNIST dataset.
4. **M5_Decision Trees.ipynb** - Decision tree implementation and visualization.
5. **M7DecisionTreeAdaboostTutorial.ipynb** - Combining decision trees with AdaBoost for improved performance.
6. **M8RegressionTutorial.ipynb** - Comprehensive guide to regression techniques.
7. **M11_KerasMNISTTutorial.ipynb** - Keras-based implementation for MNIST.
8. **M13_MNISTVariousAlgorithmsTutorial.ipynb** - Comparing algorithms on the MNIST dataset.
